# Archived scripts

One-off investigation and data-fix scripts from earlier months (April
spending checks, February report regeneration, the 2026-10-01 rule
hygiene pass, etc.). They are kept for reference and are not part of any
`npm run` command or schedule. Run them from the repo root, as before:

```
npx tsx scripts/archive/<name>.ts
node scripts/archive/<name>.mjs
```
