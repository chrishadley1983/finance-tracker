# Sizing by budget, two-gilt fixture

Rule: redemption per year = budget ÷ Σ(cost of £1 real redemption per target year), and the cost of £1 real
redemption of a linker is clean/100 (face = real/indexRatio, cost = face × dirty/100, indexRatio = dirty/clean).

Fixture: gilt A matures 2035, clean 80; gilt B matures 2036, clean 60; budget £140,000 over 2035–2036.

- Cost per £1 real: 0.80 + 0.60 = 1.40
- Redemption per year = 140,000 / 1.40 = **£100,000**
- Check: 100,000 × 0.80 + 100,000 × 0.60 = 140,000 ✓

The fixture's dirty prices do not matter for the size (they only set the nominal face to order).
